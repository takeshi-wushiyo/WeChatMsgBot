# WeChat Message Bot

## 项目描述

这是一个用Python编写的WeChat消息机器人项目。该项目可以帮助用户自动化发送WeChat消息。

## 使用方法

1. 运行`main.py`。

2. 当提示选择CSV文件时，选择包含`G`列为发送标志，`H`列为称呼，`I`列为消息内容的CSV文件。

3. 保持微信窗口打开并且不被隐藏，确保微信已切换至第一个好友的聊天界面。

4. 按照CSV文件中的信息，机器人将自动向指定的联系人发送消息。

## 注意事项

- 请确保你的CSV文件中，`G`列为发送标志（标记为“发送”的行将被机器人读取），`H`列为称呼，`I`列为消息内容。

- 在运行过程中，请不要操作鼠标和键盘，因为这可能会干扰机器人的运行。

- 在使用过程中，请确保遵守微信的使用协议和相关法规，不要发送违法或者骚扰性的消息。

# 瘦身效果预览 App（slim_visualizer.py）

## 功能简介

通过上传照片或直接拍摄，直观展示用户瘦下来之后的样子。

- 📂 **上传照片**：从本地选择图片（JPG / PNG / BMP / WebP 等格式）。
- 📸 **拍摄照片**：使用摄像头实时拍摄（需安装 `opencv-python`，按空格键拍摄）。
- ⚖️ **瘦身幅度**：通过滑动条调整 5%–50% 的收缩程度。
- 🔧 **两种变换方式**：
  - **本地处理（快速）**：基于 PIL + NumPy 的横向收缩算法，无需联网，实时预览。
  - **AI 生成（OpenAI）**：调用 DALL-E 3 生成真实感更强的效果（需有效的 OpenAI API Key）。
- 💾 **保存结果**：将瘦身效果图保存为 PNG 或 JPEG 文件。

## 安装依赖

```bash
pip install -r requirements_slim.txt

# 可选：摄像头拍照
pip install opencv-python

# 可选：AI 生成
pip install openai
```

## 使用方法

```bash
python slim_visualizer.py
```

1. 点击 **上传照片** 或 **拍摄照片** 加载一张含有人物的图片。
2. 拖动 **瘦身幅度** 滑块，设置希望展示的瘦身程度。
3. 选择 **本地处理** 或 **AI 生成**（后者需填写 OpenAI API Key）。
4. 点击 **生成效果**，即可在右侧看到瘦身后的对比图。
5. 点击 **保存结果** 将图片保存到本地。

## 注意事项

- 本地处理算法使用横向收缩变换，效果基于图像几何变形，仅供参考和娱乐。
- AI 生成功能需要 OpenAI 账户及有效的 API Key，图像将上传至 OpenAI 处理。
- 请勿将此工具用于任何可能伤害他人自尊或引起不适的场景。
